# Security policy

Avow is pre-release and runs on testnet only. We still want to hear about anything that could let someone move reserved money, forge an approval or get around a mandate.

## Reporting a vulnerability

Email contact@avow.finance with "Security" in the subject line. Include what you found, how to reproduce it, and the version or commit you tested.

Please don't open a public issue or pull request for a security problem. We aim to reply within three working days and will keep you updated until it's fixed.

## Scope

- The packages in this repository
- Avow's hosted API and web app on testnet

Real-money services aren't live yet.
